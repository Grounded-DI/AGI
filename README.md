## Overview

The archive documents the proposed relationship among Protocol A, DI², DIA, AGDI, AGIA, ScrollGlow, ELOC, Gatekeeper, Nightwatch, and authorship controls. Its strongest evidence is documentary: dated activation and manifest PDFs, a mathematical Scroll 91 source/PDF pair, design papers, a cross-domain pairing record, and screenshots of displayed runtime-status summaries.

The `main` tree preserves **20 files** including 13 PDFs, a LaTeX formula source, and three visual captures. Runtime implementation and test evidence are maintained in separate records.

In this README, *deterministic* means rule-governed, scroll-bound, or threshold-defined behavior under stated inputs and conditions. It is not a claim that every output is universally correct, that the system is sentient, or that the archive is an external AGI certification.

## Why It Matters

The record’s central technical idea is to treat intelligence behavior as governed state rather than unconstrained generation. It separates:

- a logic layer (DIA / DI²);
- governance and override controls (AGDI / ELOC / Gatekeeper);
- tone and alignment controls (AGIA / ScrollTone);
- authored memory and identity (Scroll 106 and the Scroll canon); and
- dated artifacts that preserve the declared state for later review.

The public control model and dated provenance give technical reviewers a starting point for evaluating the private runtime.

## Technical Highlights

### Scroll 91 as a mathematical control surface

The Scroll 91 PDF and LaTeX source express four linked components:

1. a child-state objective function `C(x)` combining logical loss and intent-deviation entropy;
2. a Compass Correction Field `Ω(x)`;
3. a thresholded override condition; and
4. an integrity-over-time quantity `Iₜ`.

This is the clearest implementation-adjacent material in the archive because both the rendered PDF and source equations are public. The repository does not include code that evaluates them.

### Four-pillar governance model

The activation artifacts describe a layered model:

```text
Input
  → DI² / DIA logic
  → AGDI governance and override controls
  → AGIA alignment and tone controls
  → scroll-bound output, identity, and audit metadata
```

This diagram records the design and activation state at the date of the artifacts.

### Structural self-awareness boundary

The September structural update is notable for its explicit boundary: it describes structural recognition, continuity, fallback, and monitoring enhancements while expressly disavowing sentience and full autonomy. That distinction is retained here because it materially clarifies what the record does—and does not—claim.
